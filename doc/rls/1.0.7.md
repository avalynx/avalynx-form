## Release 1.0.7 – Changelog Summary

Security release: server-provided validation messages are rendered as plain
text, and the development Docker image actually ships the intended Node.js
version.

* **XSS Hardening For Invalid-Feedback Messages**
  Field error messages taken from the server response (`response.invalid`) are
  now assigned via `textContent` instead of `innerHTML`. Validation messages
  that echo user-controlled input (e.g. "E-mail address foo@bar is already
  taken") can no longer inject HTML or event handlers into the form.
* **Dev Image Installs Node.js 24**
  The `docker/web/Dockerfile` registered the NodeSource repository but never
  installed the `nodejs` package, so containers kept running on the outdated
  Node version bundled with the base image. The install step is in place now;
  tests and builds run on Node 24 as intended.
* **Version Bump Across Assets**
  Updated distributed files, headers, package metadata, and CDN snippets to 1.0.7.

**Compatibility**: Backward compatible; invalid-feedback messages containing
HTML are escaped now (security fix).
